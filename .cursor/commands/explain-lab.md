Look at the current lab directory (README, any existing files, and the folder name) and explain:

1. **Learning objective** — what concept does this lab teach?
2. **What already exists** — describe any starter files provided
3. **What the student must do** — list the concrete steps/tasks
4. **Key commands** — the exact CLI commands they'll run (docker, kubectl, terraform, etc.)
5. **How to verify success** — how will the student know they're done?

Keep the explanation beginner-friendly. Use short sentences and concrete examples.
