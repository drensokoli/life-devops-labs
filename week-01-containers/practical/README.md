# Week 1 — Part 2: Practical Lab

> This folder will be populated before the practical session.

In Part 2, you will build the complete development environment from scratch:

- Next.js frontend
- .NET API backend
- PostgreSQL
- Redis
- Keycloak
- RabbitMQ
- Kafka
- Loki + Grafana
- Nginx reverse proxy

All orchestrated with `docker-compose.yml`.
